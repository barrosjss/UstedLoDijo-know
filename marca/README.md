# Marca

Logo de Usted Lo Dijo: comillas dentro de un bocadillo de diálogo — el signo visual del
concepto del programa (lo que usted dijo queda grabado, entre comillas, para siempre).

| Archivo | Qué es | Uso |
|---|---|---|
| `logo-wordmark.png` | Wordmark completo, formato ancho | Miniaturas, portada de YouTube, banners |
| `logo-wordmark-e-icono.png` | Wordmark + variante de ícono (comillas solas) | Referencia de marca, perfil/favicon |

**Paleta:** negro `#000000` (o casi), naranja `#F15A24`-ish, fondo crema `#F7F3EC`.
Se usa en miniaturas, overlays de los sombreros (foto del día) y cualquier gráfico del
programa — ver [postproducción](../docs/07-postproduccion-y-distribucion.md).
