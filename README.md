# Usted Lo Dijo — Know How

Repositorio de conocimiento operativo del podcast **Usted Lo Dijo**. No es un repo de
código: es el manual con el que cualquiera del equipo puede entender el formato,
preparar un capítulo, grabarlo, editarlo y publicarlo sin preguntar nada.

## Decisiones duras (v1)

| Decisión | Valor |
|---|---|
| Mesa | Jesús Barros, Carlos De La Peña, Tairo Maiguel, Melissa Zogbi — 4 fijos, sin invitado |
| Duración objetivo | 45–60 min (target de edición: **52 min**) |
| Grabación | Video + audio, **YouTube first** |
| Cadencia | **Semanal**, grabando en tandas |
| Host / director | **Jesús Barros** (fijo, no rota) |
| Mediador | **El del Sombrero**: rota cada capítulo, sombrero distinto, no se ríe |
| Idioma / registro | Español barranquillero, sin neutralizar. Recocha permitida, imprecisión no |
| Eje editorial | Lo que cada uno dijo queda en el registro y se le cobra después |

Rotación del sombrero: **Carlos → Tairo → Melissa → Carlos…** (Jesús conduce; ver
[capítulo con host invertido](docs/02-panel-y-roles.md#capítulo-con-host-invertido)).

**Los tres elementos que van en todos los capítulos:** el archivo (se le cobra lo que
firmó), el sombrero (un sombrero nuevo por capítulo, quien lo lleva modera y no se ríe)
y El Dato Costeño (tres datos reales que suenan inventados). Todo lo demás rota.

## Cómo se usa este repo

1. Un tema nace como [brief](plantillas/brief-tema.md) en `capitulos/<nn>-<slug>/brief.md`.
2. Al entrar al calendario se le crea el [guion](plantillas/guion-capitulo.md) al lado.
3. Después de grabar, el [acta](plantillas/acta-de-cierre.md) se guarda en la misma carpeta
   y se indexa en `docs/archivo-de-afirmaciones.md` (se crea con el primer capítulo).
4. Lo que cambie del formato se anota en la [bitácora](docs/99-decisiones.md), no se
   edita en silencio.
