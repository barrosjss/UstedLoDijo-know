# Archivo de afirmaciones

El registro maestro del programa: todo lo que se firmó en las
[actas](../plantillas/acta-de-cierre.md), capítulo por capítulo. De acá sale la
[cuenta de cobro](04-dinamicas.md#la-cuenta-de-cobro) de cada semana.

**Cómo se usa:** el mediador del próximo capítulo filtra por `Revisar en` ≤ mes actual
y escoge 2–3 para cobrar. Después de cobrarlas, actualiza el estado.

Estados: `PENDIENTE` · `SOSTENIDA` · `RETRACTADA` · `COBRADA`
