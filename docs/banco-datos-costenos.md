# Banco de Datos Costeños

Insumo de la sección fija [El Dato Costeño](04-dinamicas.md#el-dato-costeño). **Nunca se
llega a grabar a improvisar esta sección.**

Cada panelista mete **2 datos al mes**. Cada capítulo consume 3 (uno real, dos
inventados), así que el banco necesita por lo menos 8 sin usar para estar sano.

## Reglas

- **Inventados**: sobre categorías, no sobre personas. "Los doctores", "los taxistas",
  "los del norte": sí. Un negocio o una persona con nombre: nunca.
- **Reales**: solo entran con fuente verificable. Dato real sin link no sirve.
- El tono es de tío en un sancocho, no de listicle traducido.
