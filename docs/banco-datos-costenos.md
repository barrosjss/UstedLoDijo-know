# Banco de Datos Costeños

Insumo de la sección fija [El Dato Costeño](04-dinamicas.md#el-dato-costeño). **Nunca se
llega a grabar a improvisar esta sección.**

Desde el capítulo 1, los tres datos del segmento son **siempre reales** — el juego no es
adivinar cuál es mentira, es adivinar cuál le suena menos creíble a la mesa aunque sea
cierto (ver [99 · decisiones](99-decisiones.md)).

Cada panelista mete **2 datos al mes**. Cada capítulo consume 3, así que el banco
necesita por lo menos 6 sin usar para estar sano.

## Reglas

- **Solo entran con fuente verificable, confirmada en la fuente primaria** — no basta el
  resumen de un buscador. Si el dato tiene fecha (una encuesta, un censo), se anota el
  año; un dato viejo se dice con su año, nunca como si fuera de ahora.
- Pueden ser sobre categorías o sobre estudios/encuestas con nombre propio (si la
  encuesta la hizo una marca o empresa, se cita tal cual, sin esconderlo).
- Nunca sobre una persona, negocio o cliente identificable.
- El tono es de tío en un sancocho: el dato se lee como chisme de barrio, aunque venga
  de un estudio internacional.
